## Harjoitustehtävä 2.

HTML-elementin osien kuvaus

Esimerkkikoodi:

<h1 id="heading1">This <strong>is</strong> header 1</h1>

Koodin osien selitykset:

<h1> – HTML-otsikkoelementti, joka määrittää ensimmäisen tason otsikon (Heading 1).

id="heading1" – Attribuutti, joka antaa elementille yksilöllisen tunnisteen. Sitä voidaan käyttää esimerkiksi CSS-tyyleissä tai JavaScriptissä.

> – Aloitustagin päättävä merkki.

<strong> – HTML-elementti, joka näyttää tekstin lihavoituna.
</strong> – Sulkee strong-elementin.

</h1> – Sulkee h1-otsikkoelementin.

HTML-koodin rakenne

<h1 id="heading1">       Aloitustagi ja id-attribuutti
    This                 Tavallinen teksti
    <strong>             Strong-elementin aloitus
        is               Korostettava teksti
    </strong>            Strong-elementin lopetus
    header 1             Tavallinen teksti
</h1>                    Lopetustagi

Koodinpätkä muodostaa HTML-sivulle ensimmäisen tason otsikon. Otsikolla on yksilöllinen heading1-tunniste, ja sen sisällä oleva sana is on merkitty tärkeäksi <strong>-elementillä.
